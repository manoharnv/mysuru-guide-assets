# Mysuru Dasara Guide – public assets

Offline map packs for the Mysuru Dasara Guide app (an independent visitor app; not affiliated with the Dasara committee, police or government). Published as GitHub releases (`maps-v<N>`).

Map data © OpenStreetMap contributors, available under the Open Database License (ODbL) 1.0: https://www.openstreetmap.org/copyright. Tilesets are derivative databases of OpenStreetMap (via the Protomaps basemap build) and are offered under the same licence. Fonts: Noto Sans, SIL Open Font License 1.1.
